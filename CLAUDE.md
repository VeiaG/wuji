# Ranobes UA - Українська платформа для читання веб-новел

## Про проект

**Ranobes UA** — це сучасна веб-платформа для читання та перекладу веб-новел українською мовою. Проект побудований на основі Payload CMS 3 та Next.js 16, надаючи повнофункціональну систему управління контентом для книг, розділів, авторів, блогу та користувачів.

### Основні функції
- 📚 Каталог книг з жанрами та фільтрацією
- 📖 Читання розділів з прогресом та закладками
- ⭐ Система рейтингів та відгуків
- 💬 Коментарі до розділів
- 👤 Профілі користувачів з Google OAuth
- 📝 Блог-платформа
- 🔍 Пошук через Algolia
- 📱 Повністю адаптивний дизайн

### Технічний стек
- **Frontend:** Next.js 16 (App Router), React 19, TypeScript
- **CMS:** Payload CMS 3.0
- **Database:** MongoDB
- **Styling:** Tailwind CSS v4 (CSS-first, без tailwind.config), shadcn/ui
- **Search:** Algolia
- **Auth:** Google OAuth 2.0

## Дизайн «Бенто II» (версія 4.0)

Сайт **лише темний**. Контент групується в плитки (bento) з великими радіусами, обкладинки — без карток. Розмиті ambient-фони з обкладинок більше **не використовуються**.

### Токени та палітри
- Кольори — лише через CSS-токени з `src/app/(frontend)/styles.css`. Ніяких захардкоджених `text-blue-500`, `gray-*`, `zinc-*`.
- 6 акцентних палітр (`tangerine` за замовчуванням, `violet`, `mint`, `rose`, `lime`, `peach`) перемикаються атрибутом `data-palette` на `<html>` через next-themes (`storageKey="palette"`). Список — `src/lib/palettes.ts`, пікер — `src/components/palette-picker.tsx`.
- Ролі кольорів: `bg-background` — фон сторінки, `bg-tile` — плитки, `bg-chip` — кнопки/чипи всередині плиток, `text-soft` — текст абзаців, `text-muted-foreground` — підписи, `bg-primary`/`text-primary` — акцент.
- Акцент дозовано: primary-кнопки, активна вкладка, прогрес-бари, логотип «чи», **одна** акцентна плитка на екран.
- `Card` всередині `.bg-tile` автоматично стає `bg-chip`, а поля в ній — `bg-background` (CSS-правило в styles.css).

### Типографіка
- **Onest** (`font-sans`) — інтерфейс; **Unbounded** — заголовки через утиліту `heading-display`. Обидва через `next/font/google` у `layout.tsx`.
- Довгі назви книг: заголовки з `clamp()` і `text-wrap: balance` (вже в `heading-display`).
- Текст читання лишається на системних шрифтах: правило `.prose.font-sans` у styles.css. Не міняйте його разом зі шрифтом інтерфейсу.

### Форма та компоненти
- Радіуси: `rounded-tile` (28px), `rounded-tile-sm` (22px), обкладинки `rounded-2xl`, кнопки `rounded-xl`/`rounded-[14px]`. Тінь лише в плаваючих панелей: `shadow-float`.
- Обгортка сторінки: `container-page` (max 1280px, відступи 16/24px), проміжок між плитками `gap-3.5` (14px). Тач-цілі ≥ 44px.
- Будівельні блоки — `src/components/bento.tsx`: `Tile`, `SectionHeader`, `StatTile`, `Chip`, `ProgressBar`, `CoverGrid`.
- `BookCard` — обкладинка 2:3 + назва + жанри рядком, без рамок; бейджі поверх обкладинки — через проп `overlay`.
- Головна: поле `spotlight` у глобалі `home-page` (блок «Новинка тижня», максимум 1) + плитка «Продовжити» (для гостей — заклик зареєструватись) + цитата останнього коментаря.

### Читалка
- Хедер, тонкий прогрес-бар розділу вгорі, плаваюча панель (зміст, ‹, прогрес, коментарі, ›, Aa), плитки «Попередній / Наступний / Обговорення» в кінці.
- Фон тексту (`settings.readerBackground`: `theme` / `light` / `sepia`) — атрибут `data-reader-bg` на обгортці перераховує токени локально. Плаваюча панель лишається темною.
- Налаштування читання зберігаються в localStorage `settings`; читати їх лише через `getInitialSettings()` із `src/globals/settings.ts`.

### Мобільна версія
- Хедер не sticky. Нижня навігація — плаваюча заокруглена панель, активний пункт — акцентна «пігулка». На сторінці читання прихована.

## Для розробників

При роботі з дизайном:
- ✅ Використовуйте `container-page`, `Tile` та інші компоненти з `bento.tsx`
- ✅ Лише токени кольорів; перевіряйте вигляд у кількох палітрах
- ✅ Перевіряйте десктоп (1440) і мобільну (390) ширину, довгі назви, порожні стани
- ❌ Не повертайте розмиті фони з обкладинок
- ❌ Не додавайте світлу тему для всього сайту — світлі варіанти лише для тексту читалки
